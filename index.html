🔧 How to control backend (make it team-ready)

1. GoHighLevel / Zapier Webhook (recommended)
Open index.html → find BACKEND_CONFIG.webhookUrl → paste your GHL inbound webhook or Zapier Catch Hook URL → set mode: "both" → push. All new leads will flow to GHL + stay in this dashboard as backup.
2. Google Sheets / Email / Supabase
See BACKEND.md in repo for copy-paste Apps Script, Formspree, EmailJS, Supabase examples. You can keep GitHub Pages hosting — just point webhook to external service. For full custom backend, deploy same index.html to Vercel/Netlify and add /api/leads function.
